CareerSoul — Job Search App

Mobile app User research → Hi-fi prototype

CareerSoul set out to ease the job-hunting process for university students. I ran user and market research to frame the problem clearly, then moved through lo-fi prototyping in Excalidraw to hi-fi prototyping in Figma.

To validate the design, I ran qualitative Think-Aloud interviews and measured usability with the System Usability Scale (SUS).

Kueh Quest!

SUTD capstone, with CPF Board Figma & ReactJS

Working with the Central Provident Fund Board for my final-year capstone at SUTD, my team built a web-based game to help elderly CPF members navigate CPF's e-services.

I contributed to user research — interviews and focus group discussions with our target users — as well as UI design and front-end development, using Figma and ReactJS.

SingHealth Retail Audit App

Web app ReactJS · Tailwind CSS · AntDesign

Built in collaboration with SingHealth, this web app gives SingHealth staff a platform to run regular audit checks on tenants across SingHealth institutions.

I worked on the front end using ReactJS, Tailwind CSS and AntDesign, and contributed automated unit testing with Selenium to strengthen the app's reliability.
